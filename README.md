## How to Deploy to Vercel (5 minutes)

### Option 1 — Drag & Drop (Easiest)

1. Go to vercel.com and sign up with Google
2. On your dashboard tap "Add New Project"
3. Tap "drag and drop" option
4. Drag this entire `aura-app` folder into Vercel
5. Vercel builds it automatically
6. You get a live URL like `aura-velse-health.vercel.app`
7. Optional: Add custom domain like `aura.velse.health`

### Option 2 — GitHub (Best for updates)

1. Create a free GitHub account at github.com
2. Create a new repository called "aura"
3. Upload all these files
4. Go to vercel.com → Import from GitHub
5. Select your repo → Deploy
6. Every time you update files it auto-redeploys
